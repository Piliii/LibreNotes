# Introduction

LibreNotes is a private, offline-first notes app for Android, Linux and the web. Notes are written in Markdown, stored on your device, and encrypted on disk.

## Sync is optional

LibreNotes works fully on its own. There's no account to create and nothing to sign in to. Install it and start writing.

If you want the same notes on more than one device, you can connect the app to a **sync server** that you run yourself. The server only ever stores encrypted data, so it can't read your notes.

| | Without sync | With sync |
|---|---|---|
| Account needed | No | No |
| Works offline | Yes | Yes |
| Notes on multiple devices | No | Yes |
| You run a server | No | Yes |
