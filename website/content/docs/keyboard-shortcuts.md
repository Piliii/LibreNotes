# Keyboard shortcuts

Shortcuts work in the Linux and Windows desktop apps. Press `Ctrl+/` or `F1` in the app to see this list.

| Shortcut | Action |
|---|---|
| `Ctrl+N` | New note |
| `Ctrl+F` | Focus search |
| `Ctrl+E` | Toggle Markdown preview (in the editor) |
| `Ctrl+Shift+A` | Archive note (in the editor) |
| `Ctrl+Shift+Del` | Move note to Trash (in the editor) |
| `Ctrl+Q` | Quit |
| `Ctrl+/` or `F1` | Show the shortcuts list |

## Quick capture

`Ctrl+Alt+N` opens a small capture box from anywhere, even when LibreNotes is in the background. Press `Enter` to save the note, `Shift+Enter` for a new line, and `Esc` to cancel. See [Install the app](/docs/install) for platform requirements.
